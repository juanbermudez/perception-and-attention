# Sitewide accuracy audit (everything outside topic walkthroughs and region guides)

Project: `~/Desktop/basics-on-attention`. Files audited as they stood at 00:42 EDT, 28 Sep 2026. Other agents were editing during the audit; see "Resolved during the audit" at the end.

Scope: `src/content/site.ts` (overview, model notes, About, code notes), `src/content/sources.ts` (all 78 topic-level sources), `src/content/regions.ts` (50 regions: `label`, `where`), `src/content/region-anatomy.ts` (50 highlights: `label`, `context`), Papers-tab intro (`src/ui/about.ts`), Streams caption (`normalizationHtml` in `src/ui/templates.ts`), and README sections "What it does", "Accuracy" and "How it works".

Method: every DOI was resolved on Crossref, and abstracts were read on Europe PMC. Open full text was checked where a note makes a specific claim (patient numbers, coordinates, species). NCBI Bookshelf titles were checked through NCBI E-utilities, because Bookshelf pages returned a CAPTCHA. Code claims were checked by reading `brain-scene.ts`, `attention.ts`, `activity.ts`, `callouts.ts`, `materials.ts`, `explorer.ts`, `topics.ts`, `state.ts` and the build scripts. Anchor positions were checked against the decoded atlas meshes in `src/data/atlas-data.json`, at 1 scene unit = 34.48 mm (scale 0.29 per cm, from `provenance/anatomy.json`). Which Z-Anatomy structures exist was checked against the Z-Anatomy app's `Hierarchy order.txt` in the same source tree the provenance names (tree `6c7f901…`, blob `a45d444…`; its git hash matched).
